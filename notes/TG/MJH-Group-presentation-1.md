# Product Demo Reactions

- Corpus management flagged as the most critical thing to get right
  - Private-first approach well received: documents default to private, explicit action needed to share to team corpus
  - UI complexity acknowledged; will iterate on the data source/tier management screen
- Views feature well received as a replacement for manual spreadsheet updates
  - Flexible structured outputs: short answer, table, checklist, paragraph
  - Can export to CSV; future alerts/notifications when values change or go null
- Key use case raised: mechanism/target-space views, not just company-specific snapshots
  - TG often compares multiple companies pursuing the same target or mechanism
  - Views can support this: create a “mechanism search” project scoped to the full corpus, apply a comparison table view
  - Tradeoff: broad corpus access may hurt relevance and increase latency; large traversals likely need async/scheduled jobs with email notification
- Feedback ranking: RAG relevance scores shown (e.g. 0.641 vs. 0.532)
  - System handles ranking automatically; user feedback will fine-tune it over time
  - TG does not need to maintain a source-of-truth hierarchy manually
